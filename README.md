[SHA-256 checksums](https://github.com/sign-out/voyage-workbench-downloads/releases/download/v0.2.4/SHA256SUMS-0.2.4.txt)

Install the Android APK over the existing app; do not uninstall if you want to retain local projects. The signing certificate is unchanged. Extract the entire Linux archive and run `run-linux.sh`. Windows is unsigned. Android uses the existing development signing certificate. Windows and physical ARM64-phone execution are not certified.

All existing features remain, including Android Codex support, local saving, Alpha-only Voyage import/save, publication/cover-crop previews, and rubric-based cover generation/grading with Building-model defaults and manual overrides. No automatic cover upload or publication occurs.

No application-source repository or separate source archive is uploaded here. GitHub's autogenerated tag archives contain this downloads repository's documentation, not the application's source repository. Compiled JavaScript remains inspectable inside the built apps.

Third-party notices, the authorized dependency-source offer, and pinned upstream source/build access information are included in the apps under **Models & agents → Third-party licenses and dependency source offer**. Required dependency-source requests can be made through this repository's Issues page. This does not make the application-source repository a release download.

This repository does not contain supplied API keys, private worlds, user exports, account state, or signing keys. It is an independent workbench, not an official Voyage release.
